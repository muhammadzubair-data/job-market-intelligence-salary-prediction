# Data dictionary

`demo_jobs.csv` is **100% synthetic**. It is generated by `jobscope.data.generate_demo(n=750, seed=42)`, and a test checks that the committed file matches the generator value for value. It does **not** represent real vacancies, salaries or market conditions.

| Column | Type | Required | Definition |
|:--|:--|:--:|:--|
| `job_title` | string | ✔ | Job role |
| `country` | string | ✔ | Posting country (English name; about 60 names are mapped to ISO codes for the map) |
| `experience_years` | number 0–60 | ✔ | Years of experience requested |
| `employment_type` | string | ✔ | e.g. Full-time / Contract |
| `remote_type` | string | ✔ | Remote / Hybrid / On-site |
| `skills` | string | ✔ | Comma-separated skill names (free text is fine; synonyms are recognised) |
| `description` | string | ✔ | Job description (used for skills analytics, **not** as a model feature) |
| `salary_usd` | number (0, 1,000,000] | ✔ | **Annual** gross salary in USD, normalised before import |
| `source` | string | – | Provenance. Rows containing `SYNTHETIC` switch the app to demo mode |
| `posting_id` | string | – | Source identifier |

Column names are case-insensitive. Rows with a missing or invalid salary or experience, out-of-range values or exact duplicates are removed, and the app shows a count for each rule.

## Using real data responsibly

- Use only postings whose salary **currency and period are known**. Convert to annual USD with a documented exchange-rate date, and never mix hourly and annual pay.
- Check the dataset's **licence** allows your use and redistribution. Respect site terms and robots policies, and don't scrape where it isn't permitted.
- Keep a provenance log: source URLs, capture dates, coverage, collection method.
- Don't upload personal data about candidates or employees.

Possible sources to evaluate (check each licence yourself before use): public job-posting datasets on open-data portals or Kaggle with an explicit licence and disclosed salaries; official labour statistics (e.g. national statistics offices, ILOSTAT) for **macro context only**, since they are not posting-level training data.

No real-world data is shipped with this repository.
